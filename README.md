# Conversor-de-numeros
Durante minhas aulas da disciplina de Arquitetura e Organização de Computadores, vi muito sobre binários, decimais, octais e hexadecimais. Resolvi criar um conversor desses números para facilitar minhas atividades e treinar minha lógica de programação.

A utilização é simples e intuitiva. Digite um número para converter. Escolha uma base de origem e escolha uma base de conversão. Clique em converter e deleite-se com o resultado.
